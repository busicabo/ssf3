Mescat - безопасный мессенджер, для анонимного общения.

Приватное общение Сообщения доступны только вам и вашим собеседникам.
Минимум данных Для входа нужен только логин и пароль.
Простой интерфейс Чаты, группы и файлы без лишних действий.
